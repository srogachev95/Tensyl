External Workflow I/O API

Solver-neutral external workflow serialization.

SchemaError

Bases: ValueError

Raised when an external-workflow payload is malformed.

to_schema(obj, *, units=None)

Return a versioned solver-neutral schema payload.

Parameters:
  • obj (WorkflowObject) –

    Stiffness, homogenization result, canonical cell, atlas, or thermal loads.

  • units (Mapping[str, Any] | None, default: None ) –

    Optional plain mapping describing the unit system. Tensyl stores these values as metadata; it does not convert units.
Returns:
  • dict[str, Any] –

    Plain Python mapping compatible with JSON and safe YAML.
Raises:
  • SchemaError –

    If the object cannot be represented by the external workflow schema.

from_schema(payload)

Reconstruct a Tensyl object from a schema payload.

Parameters:
  • payload (Mapping[str, Any]) –

    Versioned external-workflow mapping.
Returns:
  • WorkflowObject –

    The stiffness, result, cell, atlas, or thermal loads described by the payload.
Raises:
  • SchemaError –

    If the payload is missing required fields, has unexpected fields, or violates schema validation.

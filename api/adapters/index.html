Solver Adapters

Translate a local stiffness into solver input after checking axes, units, and reference surface. See the solver handoff for the supported Abaqus contract and its verification limits.

Return full ABD and transverse-shear keyword data in consistent units.

The caller must align Abaqus section axes and normal with stiffness.frame and place the shell at the stiffness reference surface. No offset, rotation, unit conversion, or material definition is added.

Parameters:
  • stiffness (ABDStiffness) –

    Local stiffness with engineering shear and twist components.

  • elset (str) –

    Existing element-set name (letters, digits, underscores).

  • orientation (str | None, default: None ) –

    Existing orientation name, if the default axes do not match.

  • explicit (bool, default: False ) –

    Require positive known surface mass for Abaqus/Explicit.
Returns:
  • str –

    Keyword fragment ending in a newline. Density is mass per surface area.
Raises:
  • ValueError –

    If names are invalid, shear stiffness is not positive definite, or Explicit has no positive areal mass.

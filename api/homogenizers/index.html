Homogenizers API

Tangent-plane equivalent-stiffness homogenizers.

HomogenizationFailure

Bases: Exception

Base exception for homogenization failures.

Use this when callers want to catch all Tensyl homogenization errors without also catching unrelated ValueError instances.

HomogenizationInputError

Bases: HomogenizationFailure, ValueError

Raised when a homogenizer receives malformed or unsupported input.

ValidityContext dataclass

Optional geometric scale data for tangent-plane validity checks.

characteristic_height is a stiffness or stiffener height scale, pitch is the repeated-cell spacing, min_radius is the smallest local curvature radius, and response_length is the intended structural response length such as a buckle wavelength or analysis feature size.

Attributes:
  • characteristic_height (float | None) –

    Optional positive member or wall height scale.

  • pitch (float | None) –

    Optional positive repeated-cell pitch.

  • min_radius (float | None) –

    Optional positive curvature radius, or infinity for flat geometry.

  • response_length (float | None) –

    Optional positive structural response length.

ValidityReport dataclass

Machine-readable validity diagnostics attached to a result.

Attributes:
  • h_over_R (float | None) –

    Height-to-radius ratio when both inputs were available.

  • p_over_R (float | None) –

    Pitch-to-radius ratio when both inputs were available.

  • p_over_L_response (float | None) –

    Pitch-to-response-length ratio when both inputs were available.

  • coupling_ratios (Mapping[str, float]) –

    Named normalized coupling indicators.

  • warnings (tuple[str, ...]) –

    Stable warning identifiers for violated checks.

HomogenizationResult dataclass

A homogenization result and its verification context.

The stiffness is returned with validity attached so warnings remain available when only result.stiffness is passed to fields, exports, or downstream tools.

Attributes:
  • stiffness (ABDStiffness) –

    Homogenized linear ABD stiffness.

  • validity (ValidityReport) –

    Validity report attached to the stiffness.

  • diagnostics (dict[str, Any] | MappingProxyType[str, Any]) –

    Read-only numerical diagnostics from the homogenizer.

  • assumptions (tuple[str, ...]) –

    Modeling assumptions made by the homogenizer.

  • source (Literal['energy', 'direct_ec', 'rve', 'imported']) –

    Identifier for the homogenization path that produced the result.

assumptions instance-attribute

reduced_orthotropic_properties(t_eff, *, tolerance=1e-09)

Return membrane-equivalent orthotropic properties.

Parameters:
  • t_eff (float) –

    Positive effective wall thickness used to convert membrane stiffnesses into engineering constants.

  • tolerance (float, default: 1e-09 ) –

    Absolute tolerance for warning about discarded off-axis or coupling terms.
Returns:
  • ReducedOrthotropicProperties –

    Orthotropic membrane constants reduced from self.stiffness.
Raises:
  • ValueError –

    If t_eff is not positive or the reduced compliance terms are not physically admissible.

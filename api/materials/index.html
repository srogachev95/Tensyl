Materials API

Material value objects and laminate plate builders.

IsotropicMaterial dataclass

Plane-stress isotropic material.

Attributes:
  • E (float) –

    Positive Young's modulus.

  • nu (float) –

    Poisson ratio satisfying -1 < nu < 0.5.

  • density (float | None) –

    Optional nonnegative mass density. When present, plate builders can report areal mass.

E instance-attribute

G property

Return the isotropic shear modulus.

Returns:
  • float –

    E / (2 * (1 + nu)) in the same unit system as E.

OrthotropicPlyMaterial dataclass

Orthotropic lamina material in local 1-2-n axes.

Attributes:
  • E1 (float) –

    Positive Young's modulus in the material 1 direction.

  • E2 (float) –

    Positive Young's modulus in the material 2 direction.

  • G12 (float) –

    Positive in-plane shear modulus.

  • nu12 (float) –

    Major Poisson ratio. The reciprocal ratio is inferred from minor symmetry.

  • G13 (float) –

    Positive transverse-shear modulus in the 1-n plane.

  • G23 (float) –

    Positive transverse-shear modulus in the 2-n plane.

  • density (float | None) –

    Optional nonnegative mass density.

transformed_reduced_stiffness(angle_rad)

Return transformed in-plane reduced stiffness for a ply angle.

Parameters:
  • angle_rad (float) –

    Ply angle from the local 1 direction to the laminate frame, in radians.
Returns:
  • FloatArray –

    Read-only transformed 3x3 reduced stiffness matrix.
Raises:
  • ValueError –

    If angle_rad is not finite.

  • ValueError –

Ply dataclass

One laminate ply for laminate_plate.

Attributes:
  • material (PlyMaterial) –

    Isotropic or orthotropic ply material.

  • thickness (float) –

    Positive ply thickness.

  • angle_rad (float) –

    Ply angle in radians. Isotropic plies ignore the rotation numerically but still preserve the input.

  • label (str) –

    Optional human-readable ply label.

isotropic_plate(material, thickness, *, shear_correction=5.0 / 6.0, frame=DEFAULT_FRAME, convention=DEFAULT_STRAIN_CONVENTION, metadata=None)

Build a skin-only isotropic plate stiffness about its mid-surface.

Parameters:
  • material (IsotropicMaterial) –

    Isotropic material for the plate.

  • thickness (float) –

    Positive plate thickness.

  • shear_correction (float, default: 5.0 / 6.0 ) –

    Positive transverse-shear correction factor.

  • frame (Frame2D, default: DEFAULT_FRAME ) –

    Local frame attached to the returned stiffness.

  • convention (StrainConvention, default: DEFAULT_STRAIN_CONVENTION ) –

    Generalized strain convention for the returned stiffness.

  • metadata (dict[str, Any] | None, default: None ) –

    Optional provenance metadata. source defaults to "isotropic_plate".
Returns:
  • ABDStiffness –

    Linear ABDStiffness with zero membrane-bending coupling and

  • ABDStiffness –

    transverse shear stiffness. Areal mass is included only when material

  • ABDStiffness –

    density is available.
Raises:
  • ValueError –

    If thickness or shear_correction is not positive.

laminate_plate(plies, *, shear_correction=5.0 / 6.0, frame=DEFAULT_FRAME, convention=DEFAULT_STRAIN_CONVENTION, metadata=None)

Build a laminate plate stiffness from bottom-to-top plies.

Parameters:
  • plies (Iterable[Ply]) –

    Iterable of plies ordered from the negative-normal face to the positive-normal face.

  • shear_correction (float, default: 5.0 / 6.0 ) –

    Positive transverse-shear correction factor.

  • frame (Frame2D, default: DEFAULT_FRAME ) –

    Local frame attached to the returned stiffness.

  • convention (StrainConvention, default: DEFAULT_STRAIN_CONVENTION ) –

    Generalized strain convention for the returned stiffness.

  • metadata (dict[str, Any] | None, default: None ) –

    Optional provenance metadata. source defaults to "laminate_plate".
Returns:
  • ABDStiffness –

    Linear ABDStiffness integrated about the laminate mid-surface.

  • ABDStiffness –

    Unsymmetric stacks naturally produce nonzero B coupling. Areal mass

  • ABDStiffness –

    is included only when every ply material supplies density.
Raises:
  • ValueError –

    If no plies are supplied or shear_correction is not positive.
